# v0.2.5 implementation plan

**Goal:** Stop the Discord countdown during stopped game phases and apply the
requested compact activity layout without changing the README style or folders.

**Design:** Active regulation uses an end timestamp; overtime uses an elapsed
start timestamp. Stopped phases omit ticking timestamps and show the last game
time in static text. Overtime resume excludes stopped time. Score, player stats
and rank artwork come from the existing reducer/config. Casual/training have
only map artwork. No additional data source or dependency is introduced.

**Assumptions:** The Casual example's “Ranked 2v2” is a copied sample; actual
playlist names remain authoritative. Discord supports start/end timestamps,
with no pause flag, so a frozen native green countdown cannot be requested.
The static stopped value is the compatible presentation; rate budgets still apply.
